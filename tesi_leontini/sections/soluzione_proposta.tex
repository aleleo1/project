\section{Architettura}

L'applicazione è composta da:
\begin{itemize}
    \item \textbf{Frontend}: Astro + SolidJS, con componenti come \texttt{Container}, \texttt{Download}, e \texttt{Storico}.
    \item \textbf{Visualizzazione}: \texttt{widv-plot}, che implementa zoom, pan, selezione intervalli e supporta diversi tipi di grafici.
    \item \textbf{Backend}: Node.js con MySQL, gestito tramite \texttt{mysql-adapter}.
\end{itemize}

\section{Gestione dello stato}

Lo stato dell'applicazione (filtri, intervalli, visualizzazione) è codificato nell'URL tramite funzioni come \texttt{createQuerySignal} e \texttt{updateUrl}, permettendo la condivisione e il ripristino delle analisi.

\section{Esportazione}

La funzione di esportazione genera file HTML standalone, facilitando la condivisione dei risultati.
