# widv-plot

An interactive data visualization component for SolidJS, used in the main [Data Visualization Platform](../README.md).

## Features

- Interactive Zooming & Panning
- Date Range Selection
- Multiple Plot Types (discrete, continuous)
- Responsive Design
- Real-time Updates
- TypeScript Support
- Customizable callbacks

## Installation

```bash
npm install widv-plot
```

Peer dependencies:

```bash
npm install solid-js d3-scale
```
